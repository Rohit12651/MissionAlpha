**Honest scope note (mock backend):** the dev runtime is `RUNTIME_BACKEND=mock` — a dispatched station task cannot actually spawn real work (it ends `task.failed`, the known cli-backend limit from P4/dogfood). B4 proves the **autonomy MECHANISM** end-to-end: tick → dedupe → enqueue → `workflow.run` → (mock) failure → **failure Delivery in Inbox**, zero human. Real station output is the cli-backend upgrade (documented, not faked). This is the honest bar — same as P4.
