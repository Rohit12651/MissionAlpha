## Execution deviations (B1, disclosed)

1. **`agent-runtime/factory.mjs` SKILL_CATALOG extended (+15 `station: true` entries).** Forced by a
   pinned fact: `validateSpec()` is a CLOSED-catalog choke point, so a station cannot hold
   `scan-competitors` et al unless they exist in the catalog. Entries are read-only (`tools:["Read"]`,
   no platform, no posting, no dev), and every desc ends "Scheduled runs land in B4." Side effect:
   the factory's SkillCatalog picker now lists 24 capabilities instead of 9.
2. **`createAgent(raw, { announce })` option added.** Default `true` → every BOSS path byte-identical.
   The boot seed passes `false`: five fabricated "spawned by BOSS" heartbeats on the comms bus would
   be a lie.
3. **`agent-runtime/server.mjs` modified** (not in the Task-3 file list): boot calls `seedStations()`
   after `factory.loadRegistry()`, and `alwaysShow` gains `STATION_IDS` — without it `liveOnly`
   filters a never-run station out of `state.agents` and the deck would render nothing.
4. **Stations ship IN the tracked registry** (`factory/registry.json` + 5 `.claude/agents/*.md`).
   Required: 9 runtime test files boot `server.mjs` without a `FACTORY_REGISTRY_FILE` override, so a
   per-boot writer mutated the repo during `npm run test:runtime`. With the entries committed the
   boot call is a verified no-op (suite re-run leaves the working tree clean).
5. **Doc path correction:** scoreboard tests live in `agent-runtime/test/deliveries.test.mjs`, not
   `agent-runtime/__tests__/deliveries.test.mjs`.
6. **`useFocusTrap` does not exist** in this repo (`src/hooks/` is absent). StationModal implements
   the same minimal trap the shipped `ReviewPane` uses, per the plan's fallback clause.
7. **Role filter pills: SKIPPED** (plan's disclose-if-skipped clause). Ordering-only, as specified.
8. **Non-station (swarm) deck cards open the EXISTING inspect drawer** via `onAgent`, not
   StationModal — a swarm agent has no station skill sheet, and inventing one would be a placeholder.
9. **Bundle gate FAILS by 94 B** — see the Task-5 evidence block above. BLOCKING, not fixed in scope.
