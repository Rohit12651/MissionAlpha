# P7 — Universal Ingestion (the moat) · ADR-054

One inbox for EVERY vendor's agents. External GitHub PRs (Cursor / Codex / Devin all
deliver as PRs) + local Claude Code sessions appear as **Deliveries** beside the swarm's
own work. GitHub PRs are decidable (approve → `gh pr review --approve`, request-changes →
`--request-changes -b`, reject → `gh pr close -c`) with two-way state sync; Claude Code
sessions are READ-ONLY (visibility first).

Provenance read: program plan §P7 + §2, master-spec M5, SESSION_MEMORY P2–P6 exits, and the
live code (deliveries.mjs / pr.mjs / events.mjs / policy.mjs / db.mjs / server.mjs / the
inbox UI). Caveman-terse.

## Security posture (BLOCKING — untrusted external content + outbound gh)
- PR titles/bodies/author/session content = UNTRUSTED. Scrubbed (SECRET_RE+ext+ctrl) at mint; rendered as text nodes only; never into a prompt.
- External deliveries can NEVER auto-apply: `mintExternal` skips `maybeAutoApply`; `autoApprove` hard-refuses `source!=='swarm'`.
- gh actions (approve/merge/close) are outbound + irreversible-ish → gated by the SAME needsAuth (token+origin+host) + client F3 as a local approve. gh-first decide: the row flips only after gh returns ok (never fabricate).
- All gh calls argv-array + shell:false + safeEnv (strips creds). Token stays in gh's keychain.
- merge-on-approve default OFF (approve only posts a review).

## Known risks / deferred (labeled)
- **gh is NOT installed on this machine** — ALL gh interaction is via an INJECTED runner in tests + a documented manual path. The real-GitHub path (approve → PR approved on github.com) is **UNPROVEN-HERE**; BOSS must `brew install gh && gh auth login`. Same posture as the P5 PR rung.
- Claude Code read-only rows stay `pending` (no decide) → they count toward the pending badge; separated by the External filter. Visibility-only v1 per spec; decide-in-Claude-Code later.
- fs.watch on macOS fires multiple events → debounced; session "finished" = transcript file mtime stable past debounce window (heuristic).
- Security sign-off + adversarial review + browser proof owned by Fable (BLOCKING sr-security after: untrusted external content + outbound gh actions).
