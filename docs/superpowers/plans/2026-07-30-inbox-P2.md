## Design decisions locked before coding

1. **ULID** (ADR-051 §6) — implemented inline in `deliveries.mjs`, no new dependency: 10-char Crockford-base32 timestamp (48-bit ms) + 16-char randomness, monotonic within the same millisecond by incrementing the random field. Regex `^[0-9A-HJKMNP-TV-Z]{26}$`.
2. **Double-mint prevention is STRUCTURAL, not advisory** — a partial unique index on an expression, so the DB itself refuses a second pending row for the same work unit. Zero schema-column deviation from ADR-051 §2:
   ```sql
   CREATE UNIQUE INDEX IF NOT EXISTS idx_deliveries_pending_key
     ON deliveries(COALESCE(taskId, 'agent:' || agentId)) WHERE status = 'pending';
   ```
   Verified empirically: duplicate pending → `SQLITE_CONSTRAINT_UNIQUE`; after the first row is decided, a fresh mint succeeds.
3. **`taskId` is the broker routing key.** Engine-minted deliveries carry `taskId='task_<hex>'` → decided through `engineBroker` (worktree). Manual `/run`-minted deliveries carry `taskId=null` → decided through the manual copy-sandbox broker keyed by `agentId`. No new column, no overloading.
4. **Mint points (both reuse `listChanges`, never a new diff walk):**
   - engine: the `DIFFED→GATING` transition, via the new `onDiffed` hook (ADR-051 §4).
   - manual: `/run` completion (`res.on("close")`) + `GET /changes` returning non-empty (ADR-051 §4 fallback). Both call the same `mint()`; the unique index makes a double call a no-op that returns the existing row.
5. **`auto_approved` is BLOCKED** (ADR-051 security table, reserved for ADR-053/P6): `decide()` refuses the verb, and `mint()`/`applyDecision()` assert the status is never that value. A dedicated test proves it.
6. **Emit-on-persist**: `events.emit()` is called by the SAME function that writes the row, inside the same synchronous block. No poller.
7. **Egress scrub**: `deliveries.mjs` and `events.mjs` both receive `server.mjs`'s existing `scrub` by injection. Neither forks `SECRET_RE`.
8. **Patch format**: real unified diff per changed path at `data/patches/<id>/<relPath>.patch` (ADR-051 §3). `before`/`after` are already truncated to 4000 chars by `broker.mjs`, so an LCS line diff is cheap and exact — accurate `diffAdditions`/`diffDeletions` for the row and for P6's risk router.
