## NO-DOLLARS invariant (BOSS hard rule — asserted in tests)
- `usage.mjs` already drops `total_cost_usd`. P8 store + tick + UI + export code render **only** token counts + context%. If `claude -p` ever returns a cost field it is IGNORED (tokens only).
- Test: assert no `$` / `cost` / `usd` / currency in the usage store output, the `usage.tick` payload, the export bundle (JSON + CSV), AND a **grep of the built `dist/` bundle** proves no `$`-cost string reaches the shipped UI.

## Security posture (light — export endpoint)
- Export route on the SAME token+origin+loopback-Host `needsAuth` gate as `/apply` — read-only but audit data is sensitive.
- Every section scrubbed on egress via the shared `scrub` (SECRET_RE + ext + ctrl). Test: a secret planted in an AUDIT.log line is REDACTED in the export.
- `from`/`to` parsed as ISO/epoch, clamped; unparseable → safe defaults (all-time or empty), never a SQL error (parameterized).
- Streamed with backpressure-safe `res.write`; row cap bounded by the range, not user-supplied `limit`.

## Known risks / deferred (labeled)
- **Real-field (est:false) token parse needs the cli backend** — the mock has no usage JSON. Proven by a UNIT test feeding a captured `stream-json` `result.usage` frame into the store; the chars/4 estimate path (`est:true`) is proven live on the mock. Same cli-only posture as the engine write-loop.
- **Native Electron save-dialog bridge deferred** — blob download is the cross-surface path (works in packaged Electron via Chromium). A native save dialog would need a new file-writing IPC surface; skipped to keep the change surgical + avoid new attack surface pre-security-review.
- Context window is a documented constant (`RUNTIME_CONTEXT_WINDOW`, default 200k) — all current tiers share ~200k; becomes a per-tier map only if a window diverges (unchanged from ADR-030).
- Browser proof + light security sign-off (export scrub/gate) owned by Fable after.
